# Sobre mim

Me chamo Yure Gabriel, tenho 19 anos e sou natural de Recife, Pernambuco. Antes de 
migrar para o Senac, cursei dois períodos de Análise e Desenvolvimento de Sistemas na 
UNINASSAU como bolsista. Atualmente, sigo o curso de ADS pela Faculdade Senac 
Pernambuco, através do Programa Embarque Digital.


Tenho interesse tanto em Desenvolvimento de Software quanto em Análise de Dados, áreas 
que considero complementares.
